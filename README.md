# 3Mash Tema Kılavuzu

3Mash ikas temasını düzenlemek ve yönetmek isteyenler için hazırlanmış kapsamlı tema kılavuzu.

## Projeyi Çalıştırma

Gereksinimler:
- Node.js (v18+)
- pnpm veya npm

### Bağımlılıkları Yükleme
```bash
npm install
```

### Derleme (Build)
```bash
npm run build:site
```

### Yerel Sunucu (Local Preview)
```bash
npm run serve
# veya port ile:
npx docusaurus serve --port 3000
```
