# Ürün Sıkça Sorulan Sorular

Bu bölüm, ürünle ilgili soruları açılır cevaplar biçiminde gösterir.

## Ne zaman kullanılır?

- Kullanım, uyumluluk, teslimat veya teknik gereksinim soruları tekrarlanıyorsa.
- Satın alma öncesi belirsizlikleri azaltmak istiyorsanız.

## Studio’da kurulum

1. Bölüm başlığını ve yan açıklamayı girin.
2. Soruları ve cevaplarını ürünle ilgili olacak şekilde yazın.
3. İlk sorunun açık gelip gelmeyeceğini belirleyin.
4. Kullanmadığınız soru alanlarını gizleyin.

## Sık kullanılan ayarlar

| Studio alanı | Ne için kullanılır? |
| --- | --- |
| Bölüm başlığı | SSS alanının konusunu açıklar. |
| Soru ve cevaplar | Açılır maddelerin içeriğini oluşturur. |
| İlk soruyu açık göster | Sayfa açıldığında ilk yanıtı görünür yapar. |
| Ürün | Bölümü ikas ürün verisiyle ilişkilendirir. |

## Gelişmiş ayarlar

| Ayar grubu | Kullanım |
| --- | --- |
| Görünürlük | Tek tek SSS maddelerini açıp kapatır. |
| Renkler | SSS alanının görsel stilini düzenler. |
