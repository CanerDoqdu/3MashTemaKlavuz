# Ürün Paket İçeriği

Bu bölüm, ürün paketini öne çıkan bir kart, paket maddeleri ve alt garanti bandıyla açıklar.

## Ne zaman kullanılır?

- Ziyaretçinin satın aldığında ne alacağını açıkça göstermeye ihtiyaç varsa.
- Aksesuar, sarf malzemesi veya paket kapsamı karar vermeyi etkiliyorsa.

## Studio’da kurulum

1. Bölüm başlığını ve açıklamayı ekleyin.
2. Paket görselini, rozetini ve başlığını girin.
3. Her paket maddesini sıra, başlık, açıklama ve varsa etiketiyle doldurun.
4. Alt garanti bandını düzenleyin.

## Sık kullanılan ayarlar

| Studio alanı | Ne için kullanılır? |
| --- | --- |
| Paket görseli ve rozeti | Öne çıkan paket kartını oluşturur. |
| Paket maddeleri | Kutunun içindekileri sıralar. |
| Alt garanti bandı | Garanti veya teslimatla ilgili kısa mesajı gösterir. |
| Ürün | Bölümü ikas ürün verisiyle ilişkilendirir. |

## Gelişmiş ayarlar

| Ayar grubu | Kullanım |
| --- | --- |
| Altıncı pakete kadar maddeler | Geniş paket içeriklerini ayrıntılandırmak için. |
